  <name>Task 1: Create ReflectionHelpers.h shared utility header</name>
  <files>unreal-plugin/MCPBridge/Source/MCPBridgeEditor/Private/ReflectionHelpers.h</files>
  <action>
Create a header-only utility file with inline/static helper functions for UE runtime reflection. This file is included by all 13 converted handlers to reduce boilerplate.

Include ONLY core engine headers that are already in Build.cs: CoreMinimal.h, UObject/UnrealType.h, UObject/PropertyPortFlags.h, Modules/ModuleManager.h, Dom/JsonObject.h, Dom/JsonValue.h, Serialization/JsonSerializer.h, Serialization/JsonWriter.h.

Define these namespace-scoped (namespace MCPReflect) inline helper functions:

1. CheckModuleLoaded(const TCHAR* ModuleName) -- returns bool via FModuleManager::Get().IsModuleLoaded()

2. FindClassByPath(const TCHAR* ClassPath) -- returns UClass* via FindObject<UClass>(nullptr, ClassPath), returns nullptr if not found

3. GetStringProperty(UObject* Obj, FName PropName) -- finds FStrProperty or FNameProperty by name on Obj->GetClass(), returns FString value or empty string. Check FStrProperty first, then FNameProperty (convert to string via ToString).

4. GetFloatProperty(UObject* Obj, FName PropName) -- finds FFloatProperty or FDoubleProperty, returns double. FFloatProperty uses GetPropertyValue_InContainer and casts to double; FDoubleProperty uses GetPropertyValue_InContainer directly.

5. GetIntProperty(UObject* Obj, FName PropName) -- finds FIntProperty or FInt64Property, returns int64.

6. GetBoolProperty(UObject* Obj, FName PropName, bool& OutValue) -- finds FBoolProperty, sets OutValue, returns bool (true if found).

7. GetObjectProperty(UObject* Obj, FName PropName) -- finds FObjectProperty, returns UObject* via GetObjectPropertyValue_InContainer, or nullptr.

8. ExportPropertyAsString(UObject* Obj, FName PropName) -- finds any FProperty by name, uses ExportTextItem_Direct to get a string representation. Returns FString (empty if not found).

9. SetPropertyFromString(UObject* Obj, FName PropName, const FString& Value) -- finds any FProperty by name, uses ImportText_Direct to set from string. Returns bool success.

10. BuildSuccessResponse(const FString& CorrId, TSharedPtr<FJsonObject> Data) -- returns FString JSON with success:true, correlationId, data fields, NO trailing newline.

11. BuildErrorResponse(const FString& CorrId, const FString& Error) -- returns FString JSON with success:false, correlationId, error fields, NO trailing newline.

12. SendModuleNotAvailable(FMCPResponseSender SendResponse, const FString& CorrId, const FString& ModuleName) -- calls SendResponse with BuildErrorResponse using error code "module_name_not_available" (lowercase module name) + trailing newline.

All helpers use ContainerPtrToValuePtr<void> for property access. Use #pragma once. Include forward declaration of FMCPResponseSender (or include MCPCommandRouter.h).

Do NOT include any optional plugin headers. Every include must resolve from the Build.cs core modules only.
  </action>
  <verify>
    <automated>grep -c "FindObject" unreal-plugin/MCPBridge/Source/MCPBridgeEditor/Private/ReflectionHelpers.h</automated>
  </verify>
  <done>ReflectionHelpers.h exists in Private/ with all 12 helper functions, includes only core headers, compiles standalone.</done>
</task>

Create MCPValidationCommands.cpp in Private/. The reflection conversion for Validation is special because the optional dependency is DataValidation (UEditorValidatorSubsystem). The key include to remove is "EditorValidatorSubsystem.h". Analysis of the .disabled file shows:

IMPORTANT ANALYSIS: Looking at the .disabled source, MCPValidationCommands includes EditorValidatorSubsystem.h, Engine/Blueprint.h, Kismet2/KismetEditorUtilities.h, AssetRegistry headers, Misc/PackageName.h. For the reflection-based version:
- Include ReflectionHelpers.h, MCPCommandRouter.h, core headers (Engine/Blueprint.h, Kismet2/KismetEditorUtilities.h, AssetRegistry, Misc/PackageName.h, JSON, Editor.h)
- Do NOT include "EditorValidatorSubsystem.h"
- At the start of validate.asset, validate.folder, and validate.project handlers, use MCPReflect::CheckModuleLoaded(TEXT("DataValidation")) -- if false, return MCPReflect::SendModuleNotAvailable

- validate.blueprint handler: UBlueprint and FKismetEditorUtilities are from core modules (Engine, Kismet) so they can use direct includes. The Blueprint compile and status check code stays unchanged from the .disabled version.
- Response JSON format must be identical to the .disabled version

Keep the same SendSuccess/SendError lambda pattern as the .disabled file, or use MCPReflect::BuildSuccessResponse/BuildErrorResponse. Either approach is fine as long as JSON output matches.

Keep path validation (FPackageName::IsValidLongPackageName, starts-with checks) identical to the .disabled version for security.
