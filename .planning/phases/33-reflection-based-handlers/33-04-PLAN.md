- gas.abilities: Check MCPReflect::CheckModuleLoaded(TEXT("GameplayAbilities")). If false, return module_not_available. - gas.effects: Find UGameplayEffect via FindObject<UClass>(nullptr, TEXT("/Script/GameplayAbilities.GameplayEffect")). Load effect assets. Read Modifiers, DurationPolicy, StackingType via FProperty iteration. FArrayProperty for modifier arrays, read each modifier's Attribute, ModifierOp, etc. via struct property reflection.
- gas.attributes: Find UAttributeSet via FindObject<UClass>(nullptr, TEXT("/Script/GameplayAbilities.AttributeSet")). List subclasses via AssetRegistry. For each AttributeSet CDO, iterate FNumericProperty/FFloatProperty fields to find gameplay attributes (skip non-float properties).
- gas.tags: This uses GameplayTagsManager which IS in Build.cs (GameplayTags module). Can use direct API: UGameplayTagsManager::Get().GetSingleTagContainer() etc. No reflection needed for tag queries. Keep implementation identical to .disabled.
